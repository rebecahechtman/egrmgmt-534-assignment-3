# Treasury & Mortgage Monitor — GitHub Pages edition

This repository hosts a static website for EGRMGMT 534 Assignment 3 at https://rebecahechtman.github.io/egrmgmt-534-assignment-3/. `index.html` is the entry page; its CSS, JavaScript, data, and downloadable CSV are in the same folder. All local links are relative so the page works at a GitHub Pages project path.

The site plots a standardized Treasury duration measure alongside the 10-year ACM term premium from 2019 onward. It also compares the term premium with the U.S. 30-year fixed mortgage rate for a selected window. Data was retrieved November 9, 2026; the site labels it as a historical snapshot.

GitHub Pages serves the root of the `main` branch. The website uses a saved historical dataset; it does not automatically refresh. The public URL appears in the completed workbook’s Website Question tab.
