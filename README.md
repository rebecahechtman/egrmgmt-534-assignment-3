# Treasury & Mortgage Monitor — GitHub Pages edition

This folder is a static website prepared for EGRMGMT 534 Assignment 3. It has not been published. `index.html` is the entry page; its CSS, JavaScript, data, and downloadable CSV are in the same folder. All local links are relative so the page can live at a GitHub Pages project path.

The site plots a standardized Treasury duration measure alongside the 10-year ACM term premium from 2019 onward. It also compares the term premium with the U.S. 30-year fixed mortgage rate for a selected window. Data was retrieved November 9, 2026; the site labels it as a historical snapshot.

After the student selects a repository and authorizes publication, place these files at the root of its `main` branch. Then enable GitHub Pages under repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Once the public URL works, replace the old URL in the workbook's Website Question tab and upload the updated workbook to Canvas.
